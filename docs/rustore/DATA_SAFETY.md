# RuStore — декларация данных и разрешений

Состояние для первой публичной версии без рекламы и аналитики.

## Данные пользователя

**Собираемые данные:** нет.

**Передаваемые третьим лицам данные:** нет.

Изображения, выбранные пользователем, обрабатываются локально и не считаются собираемыми приложением данными, поскольку не отправляются разработчику или третьим лицам.

## Доступ к изображениям

Используется системный Android Photo Picker. Приложение получает доступ только к выбранному пользователем изображению, без общего разрешения на чтение всей фотогалереи.

## Сохранение

Для сохранения результата используется системный Create Document / Storage Access Framework поток, в котором место назначения выбирает пользователь.

## Сетевой доступ

В первой публичной версии отсутствует permission INTERNET.

## Чувствительные разрешения

Нет.

## Что проверить в RuStore Console после загрузки APK/AAB

1. Список обнаруженных permissions.
2. Что RuStore не определил чувствительные или запрещённые permissions.
3. В разделе пользовательских данных указать отсутствие сбора и передачи данных.
4. Если Console трактует системный Photo Picker иначе — описать доступ как локальную обработку только выбранного пользователем изображения.
