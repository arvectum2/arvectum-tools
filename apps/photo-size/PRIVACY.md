# Политика конфиденциальности — «Фото под размер»

Дата редакции: 30 сентября 2026 г.

Правообладатель приложения: ООО «Арвектум».

## 1. Какие данные обрабатывает приложение

«Фото под размер» работает с изображениями, которые пользователь самостоятельно выбирает через системный интерфейс выбора фотографий Android или iOS.

Обработка выбранных изображений выполняется локально на устройстве пользователя. Содержимое выбранных фотографий не передаётся в рекламную сеть и не загружается на серверы ООО «Арвектум».

## 2. Передача и сбор данных

Приложение:
- не требует регистрации и не создаёт пользовательские аккаунты;
- не загружает изображения на серверы ООО «Арвектум»;
- не передаёт содержимое изображений третьим лицам;
- не имеет собственного backend для обработки фотографий;
- не запрашивает доступ ко всей медиатеке устройства.

В iOS-версии используется Yandex Mobile Ads SDK для показа рекламы. Рекламный SDK выполняет сетевые запросы и может обрабатывать техническую информацию, необходимую для показа и измерения рекламы, в соответствии с настройками SDK, согласием пользователя и политиками Яндекса.

Для доступа к рекламному идентификатору приложение использует системный App Tracking Transparency (ATT) только после согласия пользователя на обработку рекламных данных. При отказе ATT реклама продолжает показываться без доступа к IDFA. Передача геолокации в Yandex Mobile Ads SDK отключена.

## 3. Хранение файлов

Исходный файл не изменяется.

Результат обработки сохраняется только по команде пользователя либо передаётся через системное меню «Поделиться». Временные файлы могут храниться в локальном кэше приложения и удаляться операционной системой или самим приложением.

## 4. Подключение к интернету

Основная функция приложения — обработка изображения — не требует доступа к интернету.

В iOS-версии подключение к интернету используется для загрузки и показа рекламных материалов через Yandex Mobile Ads SDK. Выбранные пользователем изображения в эти запросы не включаются.

Android-версия не содержит рекламного SDK и по-прежнему не содержит разрешение INTERNET.

## 5. Согласие на обработку данных

Для пользователей, на которых распространяются требования GDPR, рекламный SDK получает состояние согласия на обработку данных. Без полученного согласия приложение не передаёт рекламному SDK положительное значение UserConsent. Отказ от обработки данных не отключает рекламу: приложение остаётся бесплатным и продолжает показывать рекламные материалы с UserConsent=false.

## 6. Управление рекламными настройками

При первом запуске iOS-версии пользователь выбирает, разрешать ли Yandex Mobile Ads обработку данных для рекламы. Независимо от выбора приложение остаётся бесплатным с рекламой.

Изменить выбор для Yandex Mobile Ads можно внутри приложения через ссылку «Реклама и конфиденциальность» в нижней части экрана.

Если пользователь ранее отвечал на системный запрос App Tracking Transparency, изменить разрешение на отслеживание можно в настройках iOS. При запрете отслеживания реклама продолжает показываться, но рекламный идентификатор IDFA недоступен SDK.

ООО «Арвектум» не получает содержимое выбранных фотографий и не хранит пользовательские изображения на собственных серверах.

## 7. Изменения политики

Политика может обновляться при изменении функциональности приложения, состава подключённых сервисов или требований законодательства и магазинов приложений.
