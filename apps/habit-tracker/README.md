# Habits by Arvectum

A lightweight iOS habit tracker in the Arvectum Tools family.

## Product rule

Keep the useful habit-tracking mechanics, remove setup friction and feature clutter. A user should be able to create a habit quickly, mark it in one tap, and understand progress at a glance.

Working formula: **«всё удобное — без лишнего»**.

## Current implementation

- iOS 17+
- SwiftUI
- SwiftData, local-first
- no account and no server dependency
- daily / selected-weekday schedules
- one-tap check-in
- streak and completion-rate calculations
- recent-history editing
- system Light/Dark appearance
