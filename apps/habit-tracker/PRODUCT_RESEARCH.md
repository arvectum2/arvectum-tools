# Habits by Arvectum — Product research

Updated: 2026-10-01

## Product thesis

Habits should remain easier to maintain than the habits themselves.

The default loop stays:

1. Create a habit in seconds.
2. See only what matters today.
3. Check it off with one tap.
4. Get useful progress context without maintaining a productivity system.

## Current HabitKit baseline

As of September 2026, HabitKit's current product includes:

- yes/no, count and measure habits;
- quit habits;
- current/best streaks and completion statistics;
- daily/weekly/monthly-style goals such as 3 times per week;
- reminders and a daily review/check-in;
- Home Screen widgets;
- notes on individual days;
- categories, filters and dashboard display modes;
- archive/restore;
- import/export;
- sharing;
- many colors/icons and multiple themes.

Its own core positioning still emphasizes a very small loop: name a habit, tap once
to log a day, and watch a visual grid fill.

## Signals worth keeping

### Keep now

- local-first, no-account core;
- one-tap check/uncheck;
- corrections for past days;
- optional reminder, permission only on demand;
- current streak plus completion rate;
- visual history;
- archive/restore;
- system Light/Dark;
- very short creation flow.

### Strong post-launch candidate

- Home/Lock Screen widgets.

Widgets repeatedly appear as a high-value way to see remaining habits or a streak
without opening the app. They fit Arvectum's low-friction philosophy because they
remove interaction rather than add configuration.

### Validate before building

- flexible frequency goals such as 3/week or N/month;
- best streak;
- quantitative habits (pages, liters, reps);
- quit/break-a-habit mode;
- import/export backup;
- Apple Watch.

These can be useful, but each expands the model and UI. Add only when user evidence
shows that the simpler daily/weekday model is insufficient.

## Explicit do-not-build list for MVP

Do not add before launch:

- categories and filters;
- notes/journaling per day;
- social features, feeds or leaderboards;
- achievements/XP/gamification;
- share cards;
- multiple dashboard display modes;
- multiple reminders per habit;
- custom themes beyond system Light/Dark;
- AI coaching;
- account system or server sync;
- quantitative and quit-habit modes.

## Why

A recurring user complaint across habit/productivity apps is that setup and
maintenance become a second productivity task. Habits by Arvectum should compete
primarily on interaction cost, not feature count.
