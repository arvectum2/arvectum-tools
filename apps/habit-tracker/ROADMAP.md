## Product contract
Lightweight, free habit tracker inspired by useful HabitKit mechanics, avoiding unnecessary setup and complexity.

## MVP / validation
- [ ] Verify repository implementation and choose an accurate feature/release baseline.
- [ ] Create and edit a habit with minimal taps.
- [ ] Daily check-off and visible history/progress.
- [ ] Multiple check-offs where applicable: validate rules and UX.
- [ ] Sliding recurrence: next due date is N days after **actual** completion.
- [ ] Define timezones, late check-off, overlapping completions and streak semantics; test edge cases.

## App-specific monetization UX (hypothesis, not global policy)
- [ ] Preserve fully free core.
- [ ] No ad interruption during check-offs or habit editing.
- [ ] Experiment with delayed ad eligibility: at least 3 days + 5 cold launches + 3 completed check-offs, subject to retention validation.
- [ ] Bottom banner only outside controls; at most one native card after useful stats content.
- [ ] Compare activation thresholds only when core engagement is established.

## Later
- [ ] Validate useful HabitKit mechanics against user demand; avoid feature cloning.
