# Habit Tracker — Backlog

**Status:** discovery later

## Product direction

- simple and free;
- minimal number of actions;
- very fast habit creation;
- clear visual progress;
- intentionally smaller scope than HabitKit Pro;
- preserve only mechanics that materially improve tracking.

## Before development

1. Decompose HabitKit Pro into user jobs and interaction mechanics.
2. Separate essential mechanics from optional complexity.
3. Define an intentionally smaller MVP.
4. Validate onboarding and daily check-in tap count.
5. Decide monetization only after the usage model is clear.
