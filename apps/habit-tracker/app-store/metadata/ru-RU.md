# ChickMark — App Store RU

Название: ChickMark
Подзаголовок: Привычки без лишнего

## Описание

ChickMark — простой трекер привычек, который не превращается в ещё одну систему, которую нужно обслуживать.

Создайте привычку за несколько секунд, отмечайте выполнение одним тапом и сразу видьте прогресс. На экране «Сегодня» — только то, что действительно запланировано на этот день.

Что есть в ChickMark:
- ежедневные привычки, выбранные дни недели и гибкая цель N раз в неделю;
- серии, лучшая серия, процент выполнения и календарная история;
- нейтральный пропуск дня без потери серии;
- пауза и возобновление без удаления истории;
- локальные напоминания с действиями «Выполнить» и «Пропустить»;
- интерактивные виджеты для экрана «Домой» и экрана блокировки;
- приложение для Apple Watch и осложнения;
- команды Siri / Shortcuts для выполнения и отмены;
- светлая и тёмная темы, VoiceOver и Dynamic Type.

ChickMark работает local-first: основные данные остаются на ваших устройствах. Для работы не нужен аккаунт Arvectum.

Главный принцип — всё удобное, без лишнего.
