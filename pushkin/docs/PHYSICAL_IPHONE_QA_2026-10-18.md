# Pushkin — физическая приёмка на iPhone 13, 18 октября 2026

## Изоляция

- Mac mini, Xcode 27.1, физический iPhone 13 с iOS 27.0.1, подключение к Xcode и разрешённая UI Automation.
- QA исходники: стабильная main после PR #90 и #95. Отдельный конфиг XcodeGen pushkin/ios/project.physical-qa.yml.
- Подписанная Apple Development отдельная сборка PUSHKIN QA 1.0.0(1), bundle ru.arvectum.tools.notify.physicalqa; собственный контейнер SwiftData, без App Groups, iCloud, HealthKit. Пользовательская сборка PUSHKIN 1.0.0(2), bundle ru.arvectum.tools.notify, и её локальные данные НЕ изменены.
- UI автоматизация использует только точный QA bundle ID. Перед каждым UI тестом флаг --store-screenshot-fixture создаёт 5 синтетических записей исключительно в приватной базе тестового приложения. В QA-базе разрешено удалять данные, реальные уведомления не читаются.
