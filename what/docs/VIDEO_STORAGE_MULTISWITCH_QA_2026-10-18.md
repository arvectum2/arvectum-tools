# Ухват — проверка свободного места и повторных переключений камеры · 18.10.2026

## Задача

В многосегментном видео `VideoSegmentComposer` перекодирует один общий MOV, а затем `LocalNoteRepository` копирует его в долговременную библиотеку. При малом количестве свободного пространства это может заполнить диск и привести к повторным ошибкам сохранения. Требовалось предотвратить заведомо невозможные экспорты, не удаляя исходники.

## Реализация

- `WhatIOS/VideoStorageBudget.swift`: размеры исходных клипов суммируются с защитой от integer overflow; для одного клипа оценивается 1× суммарного объёма + 32 МиБ, для двух и более — 3× + 32 МиБ. `volumeAvailableCapacityForImportantUsageKey` используется как системный ориентир; если API недоступен, сохраняется нормальный путь сохранения с уже имеющейся безопасной обработкой ошибки `ENOSPC`.
- `VideoSegmentComposer.compose` проверяет запас места до начала `AVAssetExportSession`, в том числе для случая одного сегмента (его далее нужно импортировать). При недостатке места возвращается локализуемое через `LocalizedError` объяснение с инструкцией освободить память и повторить восстановление. Исходные сегменты/манифест не удаляются. Повторный успешный импорт очищает временный журнал по прежнему протоколу UUID.
- Оценка не может гарантировать успех при конкурирующем использовании диска, изменении битрейта или исчерпании памяти. При реальных ошибках копирования/экспорта исходники по-прежнему сохраняются механизмами `VideoCaptureRecovery` и `LocalNoteRepository`.
