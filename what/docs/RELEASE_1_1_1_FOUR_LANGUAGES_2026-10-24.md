# Ухват 1.1.1 (9) — четырёхъязычный релизный кандидат

Цель: iPhone + Apple Watch + iPhone Widget + Watch complication с RU/EN/ES/FR.
Новая версия следует после публичной 1.1.0(8); все прежние записи/группы
приложения сохраняются, bundle IDs и App Group не меняются.

- [x] В исходниках есть каталоги для четырёх языков каждого модуля.
- [x] Французские permission strings для iPhone и Watch, системные display names.
- [x] UI-язык следует настройке приложения iOS, независим от языка транскрибации;
  транскрибация fr-FR добавлена как выбираемая, при недоступности on-device
  распознавания существующий безопасный отказ оставляет оригинальное аудио.
- [x] Весь исходный французский набор создан и проверен по ключам и плейсхолдерам;
  опасные фразы об удалении/сохранности/синхронизации откорректированы вручную.
- [x] Что добавлено: French noteCount, formatting, runtime resolution unit.
- [ ] Компиляция iPhone, Watch, Widget, Xcode CI.
- [ ] Проверить четыре локали внутри подписанного IPA, включая Watch.
- [ ] Неразрушающая проверка обновления и доступа к существующим заметкам.
- [ ] Французский интерфейс, системные permissions и ASO-метаданные проверить перед App Review.
- [ ] Загрузка и App Review только по явному разрешению на конкретную версию.

Локализация выполнена с машинной помощью; отсутствие плейсхолдеров,
русских/английских заглушек и UI-тесты не гарантируют литературную точность.
Не маркировать французский как опубликованный до проверки App Store.
