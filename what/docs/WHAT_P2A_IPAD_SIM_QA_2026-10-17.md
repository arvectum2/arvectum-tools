# Ухват P2a — iPad Simulator восстановлен и UI принят (17.10.2026)

## Причина и решение инфраструктурного блокера

- Xcode 27.1 ранее имел только iOS 27.1 simulator runtime `24A94232` с ограничением `restrictedToDeviceTypes = V68` (iPhone Duo), поэтому CoreSimulator не создавал никакие iPad (ошибка 403). Этот runtime не редактировался и **остался установлен**.
- Команда `xcodebuild -downloadPlatform iOS -buildVersion 27.0 -architectureVariant arm64` нашла **обычный** iOS 27.0 runtime `24A434`, но её встроенный загрузчик самопроизвольно сбрасывал прогресс: максимум 23,7% (1,91 ГБ), потом 0%. Ошибка в выводе явным текстом не появлялась.
- Из официального каталога Apple `/System/Library/AssetsV2/com_apple_MobileAsset_iOSSimulatorRuntime/...xml` извлечена каноническая CDN-ссылка архива `AppleArchive` и контрольная SHA-256. Проверено, что CDN поддерживает HTTP Range; `aria2c` с восьмью соединениями успешно **возобновляемо** скачал архив на ArvectumSSD, 8 053 063 680 байт, средняя скорость 32 МиБ/с. Статус `aria2c`: `OK`, 100%. Архив **не публиковался в GitHub**.
- Контрольная сумма скачанного архива **совпала полностью** с Apple MobileAsset `_Measurement-SHA256`: `4dc160434bfb959ceaa86a41407f6a77bddac53bbee7e41f5a8635c8d1f75346`. Системный AppleArchive расшифрован штатным `aa patch` с ключом, полученным только из официального Apple MobileAsset каталога. Временный файл ключа после операции удалён.
- Из полученного подписанного `.dmg` штатная команда `xcrun simctl runtime add` завершилась **exit=0 / Ready**: iOS 27.0 `24A434`, UUID `3378C160-35EA-40CA-9C49-06CFBF1F1038`. `xcrun simctl runtime list -v` подтверждает **Signature State: Verified**, Apple runtime на `/Library/Developer/CoreSimulator/Images/...dmg`. Он поддерживает **62 типа устройств**, включая iPad Air/Pro/mini/обычный iPad, в отличие от Duo-only 27.1.
- После проверенной установки удалена только временная распаковка на ArvectumSSD (~7,5 ГиБ); полный 7,5 ГиБ `.aar` сохранён на SSD для повторной установки, подписанный установленный runtime и существующий Duo не удалялись.

## Реальная автоматизированная приёмка iPad

- Создан и загружен **новый, отдельный** `iPad Air 11-inch (M3)` на iOS 27.0: симулятор `Uhvat-P2a-iPad-Air11-20261017`, UDID `A6ED0363-25C2-4B2B-BFE5-38BBC7E04EB8`. Существующие iPhone Duo и Watch симуляторы сохранены.
- `WhatIOSUITests` запущены на новой iPad-среде: **четыре теста / 0 сбоев, финальное `TEST SUCCEEDED`** (лог `builds/what-p2a-ipad-air11-qa-20261017.log`):
  1. Главный экран, «Мои записи» и возврат к круглой кнопке записи.
  2. Горизонтальная ориентация, доступ к записи и «+», текстовый редактор, библиотека и возврат.
  3. Новый регрессионный тест: portrait → landscape → portrait; большая кнопка записи, `+` и переход к списку остаются `isHittable`, редактор виден и закрывается.
  4. Создание/сохранение новой текстовой заметки через «+»; заметка находится в локальном Inbox после перехода.
- Дополнительный запуск **двух** iPad-тестов / **0 ошибок по результатам XCTest cases**: длительное нажатие ведёт в «Видеозаметку» (не аудио) и текстовая заметка открывает меню напоминаний без запроса разрешения до выбора пользователем (`builds/what-p2a-ipad-air11-extra-qa-20261017.log`). **Оба теста имеют `Test Case ... passed`, `Executed 2 tests, 0 failures`, но НЕ финальное `TEST SUCCEEDED`**: Xcode 27.1 снова завис после выполнения тестов на финализации результатов, повторяя `IDESchemeActionSDKRecord invalidDigitCount(94232)`; завершена только зависшая команда Xcodebuild после успешных тестовых кейсов. Эти два кейса не считать clean full-suite run.
- На iPad тестовое приложение `ru.arvectum.tools.what.p2aqa` использовало независимое симуляторное хранилище. Ни production, ни существующие физические iPhone/Watch QA и их пользовательские файлы при этих проверках не изменялись.

## Остаётся до выпуска

- Автоматическая регрессия в портретной и альбомной ориентациях и основные UX-взаимодействия **приняты на iPad Simulator**. Но **не проверены** настоящий физический iPad, Split View/Stage Manager, пиксельная визуальная ревизия через снимки (удалённому `simctl io screenshot` macOS отказала в разрешении), реальная камера/микрофон iPad, фоновые прерывания и длинные записи на iPad.
- Xcode 27.1 выдаёт `invalidDigitCount(94232)` во время работы XCTest, иногда мешая финализации `.xcresult`; нужно вести инфраструктурный workaround, но это не отменяет полученный clean 4/4 тестовый запуск.
- Время проверки: вечер 17 октября 2026. Артефакты/логи остаются только на ArvectumSSD. **Ни один релиз в App Store не отправлялся**.
