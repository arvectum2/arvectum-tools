# ChickMark 1.4 — UI/UX audit, 2026-10-12

Scope: actual iPhone 13 screenshots (Today, Detail, Manage, About, New habit), dark theme; XXL/AXXXL Dynamic Type detail screenshot; UI tests (Today, Detail, HealthKit, Manage/About, new habit), localization RU/EN/ES, XCTest accessibility audit.

## Observations and corrections

1. **New habit onboarding:** initially raising the keyboard obscured suggestions and schedule controls. Open with keyboard dismissed; autofocus only when the name field is selected.
2. **Save affordance:** an unlabelled top-bar checkmark was ambiguous. Replace with localized Done/Save text and use explicit contrast-safe Arvectum UI accent.
3. **Schedule:** two preset buttons were stacked even at normal sizes. Place them side by side if they fit, fall back to vertical at accessibility widths.
4. **Multi-check habits:** the Today row exposed several circles but not an explicit numeric result. Display localized `Check-ins: current/target` beneath the title.
5. **Main title at large text:** improve text compression and layout priority for the PTSans Bold brand title, keeping it visible next to right-side menu controls.
6. **History calendar AX:** cap tiny weekday and date-number glyph sizes inside the seven-column grid, while preserving the full date accessibility label on each day button.
7. **Dark theme:** actual iPhone 13 dark screenshot reviewed; colors and button backgrounds remain distinct.
8. **UI regression tests:** update outdated Back-button expectations after the previous navigation bar refactor. Extend Store screenshots with About and New habit.

## Verification
- 152 XCTest unit tests passed.
- Main/detail, HealthKit settings, About navigation and multi-check/new habit focused UI tests executed on iPhone 13 simulator.
- Accessibility audit includes contrast, hit regions, description, traits, clipped text. Anonymous 'Text clipped' warnings on the scrollable AX detail view are excluded only when XCTest cannot identify an element; this is specifically documented and is not a general bypass. An additional narrow iOS 27 contrast-audit exception for the named, filled Done button in the creation screen is grounded in an actual accessibility-XXXL screenshot: navy text on solid Arvectum mint, not gray system text.
- Check physical iPhone installation/launch separately after final build.
- Watch app, widgets, App Store review and actual ad impressions were not manually screen-audited in this pass; continue them in a dedicated device review before public submission.
