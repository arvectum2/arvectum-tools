# Политика конфиденциальности — «Фото под размер»

Дата редакции: 25 сентября 2026 г.

Правообладатель приложения: ООО «Арвектум».

## 1. Какие данные обрабатывает приложение

«Фото под размер» работает с изображениями, которые пользователь самостоятельно выбирает через системный интерфейс Android.

Обработка выбранных изображений выполняется локально на устройстве пользователя.

## 2. Передача и сбор данных

Текущая версия приложения:
- не требует регистрации;
- не создаёт пользовательские аккаунты;
- не загружает изображения на серверы ООО «Арвектум»;
- не передаёт содержимое изображений третьим лицам;
- не использует рекламные SDK;
- не использует аналитические SDK;
- не имеет собственного backend;
- не запрашивает доступ ко всей медиатеке устройства.

Приложение получает доступ только к файлу, который пользователь явно выбрал через системный Android Photo Picker, и к месту сохранения, которое пользователь выбрал через системный интерфейс.

## 3. Хранение файлов

Исходный файл не изменяется.

Результат обработки сохраняется только по команде пользователя либо передаётся через системное меню «Поделиться». Временные файлы могут храниться в локальном кэше приложения и удаляться системой Android или самим приложением.

## 4. Подключение к интернету

Текущая версия приложения не требует доступа к интернету для основной работы и не содержит разрешение INTERNET.

## 5. Изменения политики

Если в будущих версиях будут добавлены аналитика, реклама или иные сетевые сервисы, настоящая политика будет обновлена до публикации такой версии.
