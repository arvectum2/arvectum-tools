# Shared dependencies — canonical management

## Single-source strategy

- **SwiftPM SDK declarations:** edit `core/dependencies/catalog.json`; run `python3 core/tools/sync_dependencies.py` to update *both* dependent iOS XcodeGen specifications. `--check` fails if they drift. Version values in generated project.yml are synchronized projections, **not independent authority**.
- **Android libraries and plugins:** edit `core/dependencies/android.versions.toml`; Android Gradle projects resolve aliases directly through the Gradle Version Catalog. No dependency versions live in the app build scripts.
- **Gradle wrapper, Kotlin/Swift language toolchains and application marketing/build versions** are separate compatibility/release contracts: leave them pinned. A single automatically floating `latest` build is prohibited because it makes releases unreproducible.
- **Shared brand code:** `core/packages/ArvectumDesignTokens/ArvectumPalette.swift` supplies the three identical base colors in ChickMark, Pushkin and Photo/PDF. Product-specific semantic colors/themes remain app-owned.

## Automatic updates

`.github/workflows/dependency-updates.yml` runs weekly and by manual dispatch. It checks official GitHub Releases and Maven metadata, selects stable versions in the *same major series*, synchronizes Swift consumers and opens a **single review PR**. If metadata is inaccessible it reports an error rather than silently inventing a latest version. Major upgrades require explicitly authorized work.

`.github/workflows/dependency-audit.yml` verifies catalogs/synchronization on PR and push. Per-app build jobs must validate shared Core changes. **The dependency PR must be approved and tested before merge.** No automatic deployment or App Store submissions follow version changes. With the default `GITHUB_TOKEN`, PRs generated by Actions may need CI triggered manually, depending on GitHub's recursive workflow protection.

Run from repository root:
```bash
python3 core/tools/sync_dependencies.py --check
python3.11 core/tools/update_dependencies.py
python3 core/tools/check_architecture.py
```

The online auditor requires Python 3.11+; the synchronization checker supports Python 3.9+.
