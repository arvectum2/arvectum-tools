## Визуальная редакторская галерея

[review-gallery.html](review-gallery.html) — локальная интерактивная галерея без сервера и без сетевых запросов. Откройте файл из рабочего checkout: на выбор все 4 приложения, 16 региональных вариантов текста и форматы iPhone/iPad. Снимки привязаны к настоящим PNG в соседних каталогах; метаданные берутся из JSON, проходящего автоматическую QA. Просмотрщик не изменяет скриншоты, не публикует ASO и не означает согласование перевода.

Галерея воспроизводится командой python3 core/tools/generate_appstore_review_gallery.py. Редакторский статус — в [C12 notes](../../docs/ASO_SCREENSHOT_EDITORIAL_NOTES_2026-10-27.md).

## Воспроизводимая работа

`prepare_appstore_localizations.py` создаёт машинные черновики и кеширует одинаковые переводы; `finalize_appstore_drafts.py` восстанавливает защищённые имена продуктов и терминологию; `plan_appstore_screenshots.py` строит slots из фактических 64 карточек; `validate_appstore_staging.py` проверяет метаданные и SHA-256 существующих изображений; `audit_editorial_all_locales.py` проверяет source-key/format/permission и формирует файл для редакторов. CI запускает проверки offline — обращение к сторонней переводческой службе в CI не требуется.
