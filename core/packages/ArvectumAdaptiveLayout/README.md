# ArvectumAdaptiveLayout — opt-in responsive UI

Shared container-width metrics and layout primitives for the two pilot consumers:
UhWhat? library/editor and Photo/PDF source/task workspace. Width rather than
hardware identity governs column layout, including Duo outer/inner windows.
The component never owns user data, navigation, recording, file export or ads.
App-specific iPad/fold/multiwindow and physical QA remain open.
