# D4.4 — ChickMark: доступность экрана «Мягкое возвращение»

Дата: 20.10.2026. Локальная feature-ветка на ArvectumSSD. Пользовательские данные, main и App Store не затрагивались.

## Найденные проблемы
На iPhone 17 Pro Simulator, iOS 27.0, при максимальном размере текста AXXXL системный аудит выявил обрезанные заголовок и подпись переключателя, а также неправильную доступность выключенного системного Picker (нет UIAccessibilityTraitNotEnabled). Первичный лог: design-d44-chickmark-restart-ax.log (FAIL).

## Решения
- Укороченный title навигации при AXXXL: Перерыв / Restart / Volver. Полный «Мягкое возвращение» остаётся видимым заголовком внутри Form с переносами.
- При AXXXL — отдельный 64pt Toggle, иконка и полная доступная подпись, без дублирующего обрезанного статического текста.
- При выключении — срок как информационный текст, а не недоступный UIKit Picker с неправильными traits. Пояснение почему срок нельзя менять находится в VoiceOver hint.
- При включении — настоящий интерактивный Picker с доступной подписью «После перерыва», иконкой календаря и высотой 64pt, без дублирующей обрезанной строки.
- Обычный Dynamic Type продолжает использовать привычные системные Toggle + Picker. Значения AppStorage, расчёт сроков и GentleRestart.minimumOptions не менялись.
- В RU, EN, ES локализованы shortTitle и disabledHint, дополнены LocalizationTests.
