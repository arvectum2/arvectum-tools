# Arvectum Tools — D4.3: второстепенные экраны и доступность

**Дата:** 20.10.2026. **Ветка:** feature/unified-design-system-20261019 (отдельный worktree на ArvectumSSD). Публикаций и изменений main не было.

## Пушкин — локальный планировщик групп

### Выявлено
Из настроек на русском открывался полностью англоязычный экран Optional Groups. При выборе приложения секция созданных групп появлялась **выше** списка поиска; строка выбора перескакивала, особенно при открытой клавиатуре/AXXXL. Выбранность передавалась только визуальным значком, мятный на белом — недостаточный контраст. Приватная подпись упускала системный буфер обмена, используемый кнопкой Copy.

### Исправлено
- Полная локализация планировщика RU/EN в существующем PushkinCopy: инструкции, поиск, группы, сохранение, очистка, статус выбора.
- Точные формы RU: 1 приложение / 2 приложения / 5 приложений / 11 приложений / 21 приложение / 25 приложений.
- Приоритет: сводка → поиск и выбор → группы → инструкция → очистка. Создание группы больше не сдвигает строку поиска вниз.
- Выбор имеет явный accessibilityValue «Выбрано»/«Не выбрано», selected trait; отметка отображается контрастным arvectumInteractiveTint.
- Поиск заканчивается действием Done/«Готово» с закрытием клавиатуры.
- Пояснение приватности: план хранится в Пушкине на iPhone, копирование использует системный буфер обмена (который может синхронизироваться механизмами платформы). Не утверждаем, что Shortcuts включён автоматически, группа по 25 — не лимит iOS.
- При AXXXL пояснения оформлены как гибкие многострочные ячейки, а не обрезающиеся футеры List Section.
- Legacy onboarding UI test адаптирован к намеренной перестановке, явной локали/вкладке и ленивой прокрутке. Данные уведомлений и Shortcuts не затрагивались. Тестовый выбор восстановлен; отдельный legacy тест проверяет выбор и очистку в QA-симуляторе.

### Подтверждено

- **EN normal:** наличие исходных строк и доступность поиска/выбора — **PASS**, design-d43-pushkin-groups-regression.log.

## ChickMark — разовое напоминание

- Связанная с напоминанием текстовая ссылка прежде использовала Mint #43E5C5 как мелкий текст на светлой поверхности (1.58:1). Теперь использует ArvectumSemanticColors.accentText(light/dark), увеличенный footnote с переносом и 44pt touch target.
- Меню «…» ранее имело доступную подпись только «Изменить», хотя также содержит удаление и другие действия. Новая подпись: RU «Действия с напоминанием», EN «Reminder actions», ES «Acciones del recordatorio».
- **RU/EN/ES localization unit tests 2/2 PASS**, design-d43-chickmark-reminder.log. UI-тест существующего demo one-off и его completion **PASS**; отдельная проверка подписи меню и 44pt **PASS**, design-d43-chickmark-actions-ui.log.
- Реальная ссылка на прикреплённую заметку в заполненных пользовательских данных не тестировалась; её текстовая контрастность соответствует общим semantic-токенам, но физическое тестирование остаётся открытым.

## Ухват — текстовый редактор

- TextEditor получил локализованное accessibilityLabel «Текст заметки» / «Note text» и пояснение «Сохраняется автоматически по мере ввода».
- Декоративный placeholder «Запишите мысль…» скрыт от VoiceOver отдельно от настоящего редактора. Autosave, создание/редактирование текстовых заметок и локальные UUID не менялись.
- **UI PASS** testAccessibilityTextSizePreservesCaptureAndEmptyTextEditor, включая проверку настоящей доступной подписи поля, отсутствие отдельного озвучиваемого placeholder, закрытие пустой заметки, возврат и фильтр библиотеки. Лог design-d43-what-text-editor.log.
- Полный сервис VoiceOver rotor/gestures, ввод реального текста/Watch/физические устройства остаются отдельными QA воротами.
