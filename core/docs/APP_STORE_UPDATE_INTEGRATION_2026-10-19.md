# Arvectum Tools — необязательные обновления App Store: интеграция 19.10.2026

**Инженерный результат:** [PR #133](https://github.com/arvectum2/arvectum-tools/pull/133) MERGED в `main`, squash 08107c324068210499cdf40afac5f3db0960510f. Исходники и тесты общие; это **не** новый бинарник в App Store.

## Что реализовано

- `core/packages/ArvectumStore/AppStoreUpdatePrompt.swift`: запрос к публичному Apple Lookup API, сопоставление точного `bundleId`, сравнение целочисленных сегментов `CFBundleShortVersionString` и опубликованной версии. Ссылка принимается только по HTTPS на `apps.apple.com`.
- Без блокировки запуска: запрос асинхронный; при офлайне, ошибке Apple или отсутствии более новой опубликованной версии предложение не показывается. Нет принудительного обновления и собственной аналитики.
- При доступной новой версии — «Обновить» (открывает App Store) или «Позже» (закрывает до следующего запуска). Тексты RU/EN/ES; `--ui-testing` не вызывает сетевые запросы.
- iOS ChickMark, Pushkin, Фото/PDF, Ухват используют общую реализацию. Для Фото/PDF проверка отложена до завершения стартового согласия на рекламу.
- Where? остаётся на паузе: только требование к будущему iOS MVP; Android Play Store — отдельный механизм и в эту реализацию не входит.

## Строгие границы готовности

**Готово:** общий Core-модуль, подключения во все 4 активных iOS-приложения и интеграция в GitHub `main`.

**Не готово / отдельное решение:** пользовательские новые версии в App Store, физическая UI-приёмка реального обновления, Android Play Store, будущая интеграция Where?. Выпуск каждого приложения разрешается отдельно после его собственного QA и согласования; новые отправки в App Store этим PR не выполнялись.

**Владение задачей:** Core [ROADMAP](../ROADMAP.md). Продуктовые ROADMAP содержат только ссылку на общий механизм и собственный release gate.
