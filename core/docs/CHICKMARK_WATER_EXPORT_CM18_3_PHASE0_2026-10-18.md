# ChickMark CM18-3 — Apple Health dietaryWater export: Phase 0 (18.10.2026)

**Status: groundwork only. This branch does NOT write Apple Health data.**
Branch feature/chickmark-water-export-20261018, from adaptive PR #90 head 4c8bfb2.

## Data model limitation

A quantitative ChickMark habit stores check-ins (1–100), not millilitres.
Neither the title Вода nor a drop icon proves the consumed volume.
No existing check-in may be interpreted as 250 ml without explicit opt-in.
Past dates before opt-in are never exported automatically.

## Implemented

- WaterExportRule: per-habit explicit amount of 10–1000 ml per check-in;
  local-only consent timestamp, no SwiftData/CloudKit schema change.
- WaterExportPlanning: pure daily reconciliation for unchanged, versioned
  upsert, update and removal only for an own previously exported record.
  Stable app-owned identifier contains habit UUID and local day key.
- WaterExportReceipt: quantity and version from the last successful write.
  Clearing opt-in preserves receipt until HealthKit deletion succeeds.
- WaterExportLocalStore: isolated UserDefaults persistence with injectable
  suite and no external SDK. No HealthKit operations.
- 12 pure unit tests: opt-in, volume, correction, idempotency, undo,
  disable, invalid dates/values, old days, clamping, local ledger.
