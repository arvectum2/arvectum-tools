# Arvectum Tools — публичные релизы и исполняемая очередь (19.10.2026)

## Источник и границы подтверждения

19.10.2026 проверен официальный публичный iTunes Lookup API Apple с `country=ru`, URL вида `https://itunes.apple.com/lookup?id=APP_ID&country=ru`. Для каждой строки `resultCount=1`; поле `version` и `currentVersionReleaseDate` читается непосредственно у Apple. Это **подтверждение публикации в RU storefront**, а не проверка новой сборки на устройстве, не статистика установок и не повторная авторизованная проверка App Store Connect. ## Что пока не делаем

- Не отправляем новый бинарник Apple автоматически, не меняем публичные карточки и рекламу без соответствующего релизного решения.
- Не удаляем и не переустанавливаем production-приложения, не делаем RESET/REPLACE реальных пользовательских данных, не запрашиваем ненужные HealthKit/Shortcuts разрешения.
- Не запускаем Where?: по-прежнему на паузе. Вопросы SEM/Ask Memory и deep Growth Agent идут после надёжности Capture/Save/Upgrade.
