## 2. Реализованные изменения и выполненный QA

**Пушкин.** Скорректированы обещания о том, какие уведомления действительно доступны iOS/Shortcuts; основные экраны локализованы, уменьшен хедер, повышена контрастность и размер действий. Системные accessibility audits Истории, Источников и Настроек **3/3 PASS**. Полный rotor, все второстепенные экраны и физические сценарии остаются открыты.

**Фото и PDF под размер.** Результирующее действие «Сохранить» вынесено из ScrollView; E2E экспорт обоих типов документов и регрессия маленьких экранов / AXXXL пройдены. Системный accessibility audit экрана результата фото и PDF **2/2 PASS**. Реальные рекламные сети, App Store и физические Files / разрешения требуют отдельной приёмки.

**ChickMark.** Точная формулировка прогресса «Отмечено» вместо ложного «Выполнено» (пропущенные привычки считаются отмеченными), локали RU/EN/ES. Панель настроек при AXXXL прокручивается, действия заполненных групп доступны в меню. Полный системный audit заполненного списка **PASS**, два unit теста локализации и две UI регрессии — **4/4 PASS**. Физический VoiceOver, HealthKit, миграция настоящих групп и исполнение удаления не тестировались этим этапом.

**Ухват.** Доступные на первом экране аудио/видео/текст, реальный счётчик и единая библиотека; у пустого состояния исчезло обрезание подсказки. В заполненном состоянии текст/видео действия адаптируются под AXXXL. Встроенные кнопки UINavigationBar не обеспечивали системный hit region; только для Accessibility Dynamic Type их заменяет собственная панель с тремя 64pt кнопками, сохранившей функции, а при обычном размере — нативная toolbar.
- Полный XCUIAccessibilityAudit заполненной библиотеки на iPhone 17 Pro: **PASS** (sufficientElementDescription, hitRegion, trait, textClipped), log what-filled-four-category-icon-record-20261020.log.
- Тот же полный audit на 13-inch iPad Simulator: **PASS**, log what-ipad13-full-ax-custom-bar-20261020.log.

## 3. Незакрытые ворота

1. Полный VoiceOver: rotor, gestures, модальные экраны, независимая физическая приемка; ранее подтверждены только ограниченные речевые сценарии.
2. Dynamic Type, контраст и Reduce Motion в остальных второстепенных интерфейсах всех четырёх продуктов.
3. iPad Split View / Stage Manager; реальные источники разрешений и camera/microphone для Ухвата; Watch ACK / синхронизация; HealthKit для ChickMark.
4. Физический Files / App Store / реклама РСЯ и реальные сохранённые данные пользователя — без разрушительных действий в рамках этой ветки.
5. Ревью кода, согласование внешнего вида, последующее независимое объединение с main и **отдельное разрешение на каждый релиз**. Ни merge, ни push, ни отправку новой версии этот QA не санкционирует.

## 4. Решение

**Внутренняя стадия D3 (симулятор и unit): готово по указанным экранам/сценариям.** Считать все четыре приложения релизно готовыми нельзя. Следующая очередь — финальное review унификации компонентов и микрокопирайтинга, затем адресное физическое QA по оставшимся воротам.
