### Важный дефект метода batch Lookup

При одиночном запросе 4 ID через один `lookup?id=id1,id2,id3,id4` тот же API возвратил закэшированные более ранние версии (в том числе Ухват 1.1.1, Pushkin 1.0.2, Фото 1.0.3), хотя **индивидуальные** запросы каждого Apple ID и региона уже возвращали C17 релизы. Поэтому C18 основан только на 64 индивидуальных запросах. Нельзя принимать batch-кэш за откат релиза.
